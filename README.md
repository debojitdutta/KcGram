# KcGram

A very simple social media website 

built as an **End-Semester College Project** for KCDCC.

## What is it?

Basically, social media.

To create posts, interact with them, and do some other social-media-ish things.

Is it revolutionary? **No.**
Does it solve a real-world problem? **Also no.**
Did the professor assign it anyway? **Absolutely.**
Did we complete it? **Nahh.**
Did we get the marks? **Hell Yeahh.** 💀

## Purpose

The primary purpose of this project is to demonstrate our understanding of web development concepts and, most importantly, **successfully survive the end-semester evaluation.**

> Built with code, confusion, deadlines, and a strong motivation to pass.
